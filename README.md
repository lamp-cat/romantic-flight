# Flyover · 低多边形俯瞰飞行

复刻 X 帖子 (notjignes/status/2113958988949942538) 里的效果：白色页面中央一块“撕纸/水彩笔触”边缘的画面，
正交俯视一片柔和、像手绘的低多边形大地，一直向北飞；中间一架白色小飞机轻轻左右摇摆，云朵在上方飘过并投下软阴影；
底部是极简的地名、季节/地貌和实时更新的经纬度。

## 四个场景
1. **Niigata, Japan** — Spring · sakura over flooded paddies（灌水稻田网格、直河、粉色樱花树和花瓣）
2. **La Pampa, Argentina** — Spring · open grassland（绿色草原、左侧土路+红色小车、右侧河流、牛群）
3. **Serengeti, Tanzania** — Dry season · long grass（金色稀树草原、土路、河、斑马群、绿树、水塘）
4. **Punjab, India** — Late winter · mustard in flower（黄色油菜花/绿色田块拼布、公路、河、树丛、带围栏的小房子、车）

## 运行
```bash
npm install
npm run dev        # 开发模式，浏览器打开提示的地址
npm run build      # 产物在 dist/，纯静态、无外部 CDN，可离线
npm run preview    # 预览构建结果
```

## 操作
- **指针操控**：鼠标/手指在画面上时，飞机平滑地飞向指针的水平位置（临界阻尼弹簧，位置和速度都连续），机头指向实际航向，
  倾斜角与转弯角速度成正比并做缓动；飞机偏离中心时镜头会跟着横移（有软边界，不会飞出内容区）
- **自动驾驶**：指针静止约 2.5 秒或离开画面后，飞机按几组频率互不成比例的正弦 + 一维平滑噪声自由漫游（不重复），
  两种模式之间用平滑权重混合，没有跳变
- `←` / `→`：等同于把指针向左/右推
- `↑` / `↓`：加速 / 减速
- `1`–`4`、`[` / `]`、底部 ‹ › 和圆点：切换场景
- 默认每 20 秒自动轮播（水彩晕开式过渡），`空格` 暂停/恢复自动轮播
- `k`：开/关轻度油画（Kuwahara）滤镜
- URL 参数：`?scene=3` 起始场景，`?auto=0` 关闭自动轮播，`?paint=0` 关闭油画滤镜

## 实现要点
- Three.js（npm + Vite）。`OrthographicCamera` 正上方俯视，每秒 27 个设计单位（从参考视频测得）。
- **无限区块流式加载**：每块 160 单位长，按镜头位置回收/复用（对象池），树、樱花、花瓣、动物、房子、围栏全部用 `InstancedMesh`。
- **地面**：`MeshLambertMaterial` + `onBeforeCompile` 注入程序化着色（`src/groundShader.js`），按世界坐标画稻田网格、河流、道路、
  Voronoi 田块等，所以区块之间无缝；带笔触噪声和每块颜色变化，并接收阴影。
- **阴影**：方向光 VSM 软阴影，阴影相机跟随镜头并按纹素对齐防闪烁；云、树、飞机、车都投影。
- **后期**（一个全屏 pass）：轻度 Kuwahara 油画滤镜 → 纸纹 + 动态胶片颗粒 → 圆角矩形 SDF + 多尺度噪声 + 飞白斑点做出撕纸边缘；
  切场景时同一张遮罩向内侵蚀再晕开。
- 经纬度：纬度随飞行距离增加（南半球数值随之减小），经度随转向偏移。
- **会动的动物**（第二版）：牛（La Pampa、Punjab）和斑马（Serengeti）每只都有独立状态——在“低头吃草”和“慢走”之间随机切换，
  平滑转向，走路时轻微上下起伏、左右摆；成群的动物围绕一个缓慢漂移的“群中心”松散聚集，掉队会走回去，并避开河流和道路。
  斑马是浅色身体加深色横纹（无 mipmap 的条纹贴图）。天上还有一小群扇翅的鸟。车沿蜿蜒的道路行驶并跟着转向。
- **更像原作的画风**（第二版）：地面加了方向变化的笔刷纹理；稻田按不规则大块划分、每块 5–8 条、颜色各异、田埂偏柔；
  道路、河流都按 `src/layout.js` 里的正弦叠加曲线蜿蜒（地面着色器和物体摆放共用同一套曲线）；
  云是中心团 + 圆瓣 + 小鼓包的“花朵”形，边缘做喷溅虚化；樱花树更大、带树干，花瓣更多更大；金合欢是扁伞状大树冠；
  撕纸边缘改成干笔飞白式喷点，并锚定在世界坐标上随飞行变化。

- **车流**（`src/traffic.js`）：每个有路的场景都有双向车流——轿车、小卡车、偶尔一辆巴士（Pampa 是皮卡、Serengeti 是越野车），
  柔和配色；车辆前后轴都落在 `layout.js` 的道路曲线上，朝向随弯道变化；每车速度不同，同车道跟车保持车距，不会重叠；
  驶出镜头前后约 560 单位后在另一端重新出现。旁遮普的车还会拐进/驶出主路西侧的支路。数量刻意保持适中。
- **铁路与列车**：新潟东侧、旁遮普西侧各有一条缓弯铁路（路基 + 碎石道床 + 枕木 + 双轨，全部画在地面着色器里），
  与农道/支路相交处是平交道口（钢轨压在路面上、两侧白色停止线）。新潟跑白色新干线（樱粉车顶线、流线车头），
  旁遮普跑红色机车 + 蓝色客车；每节车厢的前后转向架分别取轨道上的点，所以整列车沿弯道铰接弯曲。
  列车上下行交替、间隔几秒周期性出现，都投下阴影。

## 中土世界版（魔戒风格，`?world=middleearth`）

同一套画面与操作（油画滤镜、撕纸边、小白飞机、指针转向 + 不重复的自动驾驶、实时 HUD），换成四个中土地区。
全部为原创程序化低多边形美术，不使用任何电影素材或标志。

```bash
npm run middleearth   # 开发模式并直接打开 http://localhost:5173/?world=middleearth
```

也可以在任意地址后加 `?world=middleearth`（或 `?world=me`），例如 `http://localhost:5173/?world=middleearth&scene=4`
直接进入魔多；`npm run preview` 后同样加该参数。不带参数时仍是原来的地球四个场景。

1. **夏尔（The Shire）**：起伏的丘陵、篱笆围出的田块（牧场、麦田、花草地、翻耕地），带圆门的霍比特洞屋，
   蜿蜒小路上的小马车和步行的霍比特人，派对树与彩色帐篷长桌，小河边的磨坊与水塘，零星的羊和小马。
2. **洛汗（Rohan）**：随风起伏的金色草原，成群行进的骑兵（白色头马、绿色旗帜），
   山丘上带金顶大厅和木栅栏的王城（Edoras 风格），道路、溪流和野马群。
3. **瑞文戴尔 · 迷雾山脉**：块面感的雪峰、松林、峡谷中的大河与跌水、两侧支流瀑布，
   谷底草地上的白色精灵建筑和金色秋树，小径上的远征队和一位白衣骑手，偶尔有巨鹰盘旋。
4. **魔多（Gorgoroth 高原）**：灰黑火山灰平原和发光裂缝，两条流动的熔岩河，
   带放射状熔岩沟的火山口和烟柱，黑塔剪影（顶部有一点橙光），道路上行进的兽人纵队（红色旗帜、长矛）。

HUD 显示地区名、中土历法/季节文字（如 "Halimath · harvest-tide, Shire Reckoning 1418"）
和虚构的地图坐标（`lg E · lg N`，随飞行实时变化）。

```bash
npm run shots:me   # -> shots/me_scene1..4.png
npm run demo:me    # 16 秒：洛汗（骑兵、王城）→ 魔多（熔岩、火山、黑塔、兽人纵队）-> shots/demo_middleearth.mp4
npm run tour:me    # 60 秒巡游：夏尔 → 洛汗 → 迷雾山脉/瑞文戴尔 → 魔多，每段约 15 秒，撕纸转场 -> shots/me_tour_60s.mp4
```

## 截图 / 录屏
```bash
npm run shots   # 无头 Chrome（SwiftShader 软件渲染）截 4 个场景 -> shots/scene1..4.png
npm run video   # 8 秒 demo -> shots/demo.mp4（需要 ffmpeg）
npm run traffic # 16 秒车流 + 列车演示（旁遮普 → 塞伦盖蒂）-> shots/demo_traffic.mp4
npm run demo    # 16 秒 Serengeti 演示（斑马走动 + 自动驾驶 → 指针接管 → 静止后回到自动驾驶）-> shots/demo_animals.mp4
```
`shots/compare_sceneN.png` 左边是参考视频帧，右边是本实现；`shots/motion_*.png` 是跟随地面的连续裁切，可看出动物在动。截图脚本默认用 `/usr/bin/google-chrome`，可用 `CHROME=...` 覆盖。
`?capture` 模式下关闭实时循环，由脚本调用 `window.__step(dt, n)` 逐帧推进，保证截图/录屏可复现。

## 目录
- `index.html`、`src/style.css`：页面与底部 UI
- `src/main.js`：场景、区块流式加载、物体生成、飞机/云/车、交互、后期
- `src/groundShader.js`：地面着色器和后期着色器
- `src/traffic.js`：车流与列车
- `src/middleearth.js`：中土世界版——四个场景配置、地形高度（GLSL 写一份，JS 自动转译）、地面着色、建筑/树木、移动的队伍
- `src/layout.js`：道路/河流/铁路蜿蜒曲线（JS 与 GLSL 共用）和“不可站立区域”
- `scripts/shoot.mjs`：截图和录屏脚本
